This project was made to help visualize a particularly stubborn keyboard from an Underwood 5 typewriter, s/n 2394077-5, discovered in Japan with an unique hiragana-kanji keyboard. Because the keyboard contained different characters for shifted and unshifted printing, a tool like this helps visualize the typewriter; it may prove useful for additional work for other typewriter enthusiasts.

In this file, index is the code to make it work; the .json file contains my best-guess/reasoned and researched estimates of what characters are where. Read more about the actual typewriter at https://typeri.us/posts/hiragana-underwood! 



A future development -- should I get to it -- would be the addition of a keyboard identifying prediction layer or perhaps an option to add keyboards to your device. Don't count on this happening, though.
